Quick Start - API Usage

1. Register a User

curl -X POST http://localhost:8000/api/v1/auth/register \ -H "Content-Type: application/json" \ -d '{"email":"user@example.com","username":"john","password":"pass123"}'

2. Login

curl -X POST http://localhost:8000/api/v1/auth/login \ -H "Content-Type: application/json" \ -d '{"email":"user@example.com","password":"pass123"}'

3. Create Bot Task

curl -X POST http://localhost:8000/api/v1/tasks \ -H "Authorization: Bearer <your-token>" \ -H "Content-Type: application/json" \ -d '{"name":"Flash Sale","url":"https://shopee.co.id/...","target_time":"00:00:00"}'

4. Run Task

curl -X POST http://localhost:8000/api/v1/tasks/1/run \ -H "Authorization: Bearer <your-token>"
